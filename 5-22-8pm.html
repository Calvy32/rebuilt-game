GAME CONTROLS

P1 — Red Keyboard 1

WASD = Move   Q/E = Turn

Space = Shoot/Pass   X = Ability

P2 — Red Controller 1

Left Stick = Move   Right Stick X = Turn

Right Trigger = Shoot/Pass   Left Trigger = Ability

P3 — Blue Keyboard 2

↑↓←→ = Move   N/M = Turn

RShift = Shoot/Pass   RCtrl = Ability

P4 — Blue Controller 2

Left Stick = Move   Right Stick X = Turn

Right Trigger = Shoot/Pass   Left Trigger = Ability

Ability Button Uses

Blitz: Toggles intake side | Barricade: Places obstacle (max 2) | Other robots: No effect

Phantom Robot

Shots pass through walls and obstacles — only the enemy hub can stop them. Ghostly appearance.

Barricade Robot

Press Ability (X / RCtrl / LT) to place a small barrier that only enemies collide with. Max 2 barriers at a time.

Plasma Robot

Fires a slow energy ball that zaps nearby balls. Each zap adds 0.33 points to the final score. Passing shots are normal balls.

Game Modes

Triple Balls, Slippery Field, and Rapid Fire change field density, traction, and fire cadence.

Power-ups spawn temporary Speed, Ammo, Shield, and +10 Score pickups. Random Shifts changes hub activity on irregular timers after auto.
