GAME CONTROLS

P1 — Red Keyboard 1

WASD = Move   Q/E = Turn

Space = Shoot/Pass   X = Ability

P2 — Red Controller 1

Left Stick = Move   Right Stick X = Turn

Right Trigger = Shoot/Pass   Left Trigger = Ability

P3 — Blue Keyboard 2

↑↓←→ = Move   N/M = Turn

RShift = Shoot/Pass   RCtrl = Ability

P4 — Blue Controller 2

Left Stick = Move   Right Stick X = Turn

Right Trigger = Shoot/Pass   Left Trigger = Ability

Ability Button Uses

Blitz: Toggles intake side | Barricade: Places obstacle (max 2) | Drone: Deploys flying shooter

Plasma Robot

Fires a chain lightning projectile that arcs to nearby balls. Each chained ball adds +2 points to the scored ball (max 5 chains = +10).

Howitzer Robot

Fires a lobbed mortar that drags nearby balls along its path. Great for moving clusters of balls toward the hub.

Phantom Robot

Passes through walls and obstacles — only the field border stops it. Ghostly appearance.

Barricade Robot

Press Ability (X / LT / RCtrl) to place a barrier. Max 2 barriers, 3-second cooldown. Placing a 3rd removes the oldest.

Drone Robot

Press Ability to deploy a flying drone that follows you and shoots independently at the enemy hub.

Game Modes

Triple Balls, Slippery Field, Rapid React (1.33x speed), Power-ups, Random Shifts
